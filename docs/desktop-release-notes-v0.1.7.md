Kith Desktop brings the shared Kith assistant to macOS and Linux. Hosted installations connect
to Kith directly; existing custom-server and local configurations remain supported.

- Native Settings and New Conversation commands, plus Search and Quick Ask keyboard navigation.
- Hosted launch progress and retry recovery that preserve saved sessions.
- One instance per profile, minimized-window restoration, and improved Quick Ask display handling.
- Kith installer naming, universal macOS packaging, and verified stable update metadata.

macOS requires a signed, notarized universal DMG and update ZIP. Linux uses an x64 AppImage.
Windows is included only when the release has a valid signing certificate. Publish these notes
only after the release acceptance gates pass; this file is preparation, not a release announcement.
