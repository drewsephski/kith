# Kith

**Your personal AI teammate, with memory.**

Kith remembers what matters to you and helps get work done. Ask it to research a topic,
work on a project, or handle a recurring task—then pick up where you left off.

![Kith's blue companion alongside a conversation, remembered context, and a weekly research routine](./docs/readme-hero.png)

## Less busy. More you.

- **Keep the context.** Conversations and memory carry over, so you spend less time repeating yourself.
- **Get things done.** Connect your tools and let Kith work with browsers, files, and apps.
- **Build your team.** Give different teammates different jobs, and set routines for recurring work.
- **Stay in control.** Run it on your own computer or server and choose the AI models you use.

Kith is open source and in beta, with web, desktop, and mobile apps.

## Get started

Follow the [source setup guide](./CONTRIBUTING.md#run-locally) to run Kith on your
computer, or [run without Docker](./docs/host-deployment.md). Create an account and complete
the assistant setup. Connect a model if the operator has not configured one.

Desktop installers are available only when listed in [Kith releases](https://github.com/drewsephski/kith/releases).
Until then, [build Desktop from source](./docs/desktop-release.md#build-from-source).
The [upstream published images](./docs/self-host.md#published-images-no-checkout) run Rakazo,
and do not contain Kith fork changes.
