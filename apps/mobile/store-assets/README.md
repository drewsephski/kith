# Kith App Store creative assets

Generated with the built-in imagegen tool using the existing Kith companion as the identity reference.

| Asset                          | Size        | Format     |
| ------------------------------ | ----------- | ---------- |
| `kith-product-page-header.png` | 3840 × 1646 | Opaque PNG |
| `kith-search-results.png`      | 1920 × 1280 | Opaque PNG |

The generated originals were resized with macOS `sips` to Apple's accepted dimensions, without changing the composition. The header original was 1916 × 821; the search original was 1536 × 1024. These are creative illustrations for the Header and Search Results slots. Native app screenshots are separate assets and must show the actual app.

References: `packages/ui-tokens/assets/kith-companion-source.png`, `apps/mobile/assets/icon.png`; the generated header was also used as the search artwork's style reference.

Apple guidance: [Creative asset specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications/) and [asset best practices](https://developer.apple.com/app-store/asset-best-practices/).

## Header prompt

```text
Use case: ads-marketing
Asset type: Apple App Store product page header, ultrawide 21:9 landscape, target 3840 x 1646 pixels.
Primary request: Create refined launch artwork for Kith, a calm conversation-first personal AI assistant.
Input images: Image 1 is the existing Kith mascot identity reference. Image 2 is the existing app icon reference for its warm ivory backdrop and premium restraint. These are references, not screenshots to reproduce.
Scene/backdrop: A seamless warm ivory studio cyclorama, very subtle warm tonal variation, no horizon line, no set dressing.
Subject: Exactly one familiar pale powder-blue bean-shaped Kith companion, with its exact friendly identity: tall softly asymmetric pear/bean silhouette, two glossy dark oval eyes, small simple curved smile, two tiny rounded feet, round glowing cyan ear on its left side. Preserve proportions, eyes, smile, material and ear from the references. The character should feel like the same mascot rendered in a new scene.
Style/medium: Premium soft tactile 3D editorial illustration, careful dimensional shading, fine satin ceramic softness.
Composition/framing: Wide cinematic composition. Mascot near the center, fully visible with ample breathing room, about 60% of image height. Behind it, two oversized warm-white softly sculpted conversation bubbles, one on either side at different depths, partially behind the mascot. These are abstract sculptural shapes conveying conversation, with no interface, writing or icons. Keep all important elements in the central 60% safe area. Leave a quiet lower strip for App Store metadata overlays.
Lighting/mood: Soft broad natural studio light, gentle contact shadows, warm, trustworthy, approachable, peaceful.
Color palette: Ivory and near-white surroundings, existing powder-blue mascot, tiny cyan ear highlight; no other saturated colors.
Text: None.
Constraints: Opaque edge-to-edge image. Preserve brand character identity exactly. One single focal point, very clean high-end composition. No extra characters, hands or human figures, no phone/device mockups, no invented app interface, no words, lettering, logos, watermark, badges, awards, website addresses, grids, starbursts or circuitry.
```

## Search results prompt

```text
Use case: ads-marketing
Asset type: Apple App Store search results creative artwork, landscape 3:2, target 1920 x 1280 pixels.
Primary request: Create the companion search artwork for Kith's App Store launch, a calm conversation-first personal AI assistant.
Input images: Image 1 is the existing Kith mascot identity reference. Image 2 is the approved new product page header, a style and lighting reference. Preserve their mascot identity and make this feel like the same campaign in a tighter composition.
Scene/backdrop: Seamless warm ivory studio background, no horizon line, slightly warmer near the base, elegant and uncluttered.
Subject: Exactly one pale powder-blue Kith companion with the same bean/pear silhouette, two glossy dark oval eyes, tiny friendly smile, two rounded feet and cyan circular ear on its left. Keep its existing asymmetric silhouette and facial proportions. Two abstract warm-white sculptural conversation bubbles sit behind it at different heights and depths, linking the character to conversation.
Style/medium: Polished tactile 3D editorial illustration, satin soft surfaces, subtle dimension and natural shading, same treatment as Image 2.
Composition/framing: Fully visible mascot, centered in the middle 60% safe area, about 58% of image height. Keep both pale bubbles visible behind, generously inset from every edge. Slight three-quarter angle with friendly gaze toward viewer. The character, eyes and ear must remain immediately recognizable at small thumbnail size. Spacious quiet top and bottom margins.
Lighting/mood: Soft studio illumination, gentle grounded shadows, inviting and reassuring.
Color palette: Warm ivory and near-white with the existing powder-blue mascot and small cyan ear highlight, no added saturated colors.
Text: None.
Constraints: Opaque edge-to-edge artwork. Match existing brand character exactly. No extra characters, humans, hands, phone frames, app UI, writing, lettering, logos, watermarks, website addresses, awards, badges, circuitry or decorative clutter. This is brand illustration for the creative slot, not an app screenshot.
```
